About ChatSave

ChatSave is a macOS application that helps you browse and export messages from compatible local iPhone backups.

You can use ChatSave to view conversations and export your messages and attachments into supported formats.

Common Issues

iPhone is not detected

  • Make sure your iPhone is connected to your Mac using a USB cable.
  • Unlock your iPhone if prompted.
  • Make sure you have trusted the Mac on your iPhone.
  • Try reconnecting the iPhone and reopening ChatSave.

Backup is not found

  • Make sure a local iPhone backup has been created on your Mac.
  • Make sure the backup has completed before opening ChatSave.
  • Follow the instructions shown inside ChatSave to select the backup.

Messages are not loading

  • Make sure the selected backup is complete.
  • Try selecting the backup again.
  • If the issue continues, contact support with details about the problem.

Export is not working

  • Make sure you have selected a conversation.
  • Make sure ChatSave has permission to save files to the selected location.
  • Try exporting again to another folder.
